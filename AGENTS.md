# AGENTS.md

Guidance for coding agents working in this repository.

## Project Overview

**suave_rebetmc** is a managing system for the SUAVE AUV pipeline-inspection mission. It uses TypeDB (via `typedb_tactics`) as a runtime knowledge base and `adapt_x`/AAL for adaptation execution. The managed system is SUAVE; this package is the *managing subsystem* that drives it through standard ROS 2 interfaces.

## Repository Layout

```
models/tactical_retreat/   DSL source models (rebetmc_eclipse_projs Xtext DSLs)
  suave.context            ContextModel DSL
  suave.var                FeatureModel DSL
  suave.resolution         ResolutionModel DSL
  suave.tactics            Tactics DSL
models/typedb/
  suave_tactics.tql        Symlink → src-gen/suave_tactics.tql (TypeDB schema)
models/interfaces/         ROS interface descriptions (input to ros2model)
models/ros/                ROS node descriptions (input to ros2model)
models/system/             System model (input to ros2model)
src-gen/                   GENERATED — do not hand-edit
suave_rebetmc/             Python package (managing node logic)
suave_rebetmc.repos        VCS deps: suave, aal, adapt_x, ros_monitors, typedb_tactics
Dockerfile                 Extends suave-headless:dev
```

## Dependencies And Environment

- ROS 2 Humble (from `suave-headless:dev` base)
- TypeDB 2.28.3, typedb-driver 2.28.0
- Java 21 (`openjdk-21-jre`), Maven 3.9.16
- adapt_x, aal (branch `mc`), ros_monitors, typedb_tactics (branch `dev`)
- Full SUAVE stack (ardupilot, Gazebo Harmonic, MAVROS) — inherited from base image

## Build And Test Commands

Run inside the container (`suave_rebetmc`). Workspace: `/home/ubuntu-user/suave_ws`.

```bash
docker exec suave_rebetmc bash -lc 'cd /home/ubuntu-user/suave_ws && source /opt/ros/humble/setup.bash && source install/setup.bash && <command>'

colcon build --symlink-install
colcon build --symlink-install --packages-select suave_rebetmc
colcon test --packages-select suave_rebetmc --event-handlers console_direct+
colcon test-result --verbose
python3 -m pytest -q suave_rebetmc/test
```

**Mandatory lint gate:** before marking work complete, run `test_flake8` and `test_pep257` and ensure both pass.

## Docker

## Generated Code Rules

- `src-gen/` is generated by rebetmc_eclipse_projs Xtext/MWE2 workflows and by `ros2model`. Do not hand-edit.
- After editing `.context`, `.var`, `.resolution`, or `.tactics` files, regenerate `src-gen/` from the Eclipse IDE with the rebetmc plugins installed.
- `models/typedb/suave_tactics.tql` is a symlink to `src-gen/suave_tactics.tql` — never edit it directly.

## ROS Managing Subsystem Interface

Must interact with:
- `/diagnostics` (`diagnostic_msgs/DiagnosticArray`)
- `/task/request`, `/task/cancel` (`suave_msgs/srv/Task`)
- `ChangeMode` services: `/f_maintain_motion/change_mode`, `/f_generate_search_path/change_mode`, `/f_follow_pipeline/change_mode`
